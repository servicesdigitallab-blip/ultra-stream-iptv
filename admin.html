Firebase Database Connection Guide (2 Minute Setup)

Firebase Google ka official free cloud database hai. Security aur ownership ke liye, har website owner ka apna Google Firebase account hota hai taake aapka customer data aur revenue 100% private rahe.

  1. console.firebase.google.com par jayen aur apne Google account se sign in karein.
  2. "Create a project" dabayein aur project name (e.g. ultra-stream-iptv) likhein.
  3. Project dashboard par Web icon </> par click karke Web App register karein.
  4. Wahan diye gaye firebaseConfig ke parameters ko copy karke niche diye gaye box me paste karein aur "Save & Test Connection" par click karein!
