Google Firebase Firestore Cloud Database (لائیو کنکشن)

فائر بیس کلاؤڈ ڈیٹا بیس کنیکٹ کریں تاکہ ایڈمن پینل کی تمام تبدیلیاں دنیا بھر کے تمام وزٹرز کو لائیو نظر آئیں۔

📋 Option 1: Quick Paste Firebase SDK Code / JSON

فائر بیس کنسول سے پورا کوڈ (const firebaseConfig = { ... };) یا JSON یہاں پیسٹ کریں — یہ خود بخود تمام خانے بھر دے گا:

🔑 Option 2: Individual Config Keys

📖 فائر بیس اکاؤنٹ اور کیز حاصل کرنے کا آسان طریقہ:

  1. console.firebase.google.com پر جا کر "Create a project" پر کلک کریں۔
  2. پروجیکٹ بننے کے بعد ویب آئیکون </> پر کلک کر کے ایپ رجسٹر کریں۔
  3. سامنے آنے والا firebaseConfig کا کوڈ کاپی کر کے اوپر والے خانے میں پیسٹ کریں۔
  4. بائیں مینو میں Build → Firestore Database پر کلک کر کے ڈیٹا بیس "Test mode" میں بنائیں۔
  5. اوپر دیا گیا "Save Firebase Config" بٹن دبائیں اور "Test Cloud Connection" سے ٹیسٹ کریں۔
